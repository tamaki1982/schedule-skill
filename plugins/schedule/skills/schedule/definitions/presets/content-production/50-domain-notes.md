# この用途ならではの注意点

## 1. 自分たちで縮められない期間

| 何を待つか | 目安の期間 | 短縮できるか |
|---|---|---|
| 出演者・取材先の日程調整 | 5〜15稼働日 | できない。台本が半分進んだ時点で打診を始める |
| 出演者による内容の確認 | 3〜7稼働日 | できない |
| 権利元への使用許諾 | 5〜15稼働日 | できない。使う可能性が見えた時点で申請する |
| 公開先の掲載枠・配信枠の確保 | 5稼働日以上 | できない。早い者勝ち |

## 2. 後ろ倒しができない日

| 何 | なぜ動かせないか |
|---|---|
| 収録日 | 出演者と場所を押さえてある。取り直しは別日の再調整になる |
| 告知済みの公開日 | 視聴者・読者への案内が先行している |
| 連載の公開間隔 | 空くと離脱につながる |

**収録日が動かせないことが、この用途の最大の制約。**
台本が間に合わなくても収録日は来るため、台本の締切は収録日の3稼働日前に置く。

## 3. 見落としやすい作業

- 権利処理（楽曲、画像、引用の許諾）
- 収録データのバックアップと保管
- 公開時の説明文・見出し・サムネイルの用意
- 出演者への公開報告と、素材の共有
- 公開後の反応の確認

## 4. この用途で必ず記録するリスク

| 状況 | 記録する内容 |
|---|---|
| 収録日が1回しか確保できていない | 中止・撮り直しになった場合の代替日 |
| 社外の出演者・取材先が関わる | 日程が動いた場合に後続がどこまでずれるか |
| 権利処理が未完了のまま編集を進めている | 許諾が下りなかった場合の差し替え |
| 公開日が固定で、編集バッファが基準量に満たない | 修正指示を何回まで受けられるか |

---

## 変更時の影響

- 第1章に行を足すと、その待ち時間が独立したタスクとして計画に現れ、着手日が前倒しになる。

# かかる日数の基準

標準作業ごとの標準工数と、それに掛ける倍率。標準作業の一覧は `10-standard-tasks.md` にある。

## 1. 標準作業ごとの標準工数

| 標準作業 | 標準工数 | 上限側を採る条件 |
|---|---|---|
| 企画 | 2〜4人日 | 新しい形式に挑戦する場合 |
| 取材・調査 | 3〜5人日 | 社外への取材を含む場合 |
| 台本・構成 | 4〜8人日 | 尺が長い、または構成が複雑な場合 |
| 出演・取材先調整 | 1〜2人日 | 社外の出演者が関わる場合。**工数は少ないが期間は長い**（第5章） |
| 収録・撮影 | 3〜6人日 | 場所が複数ある場合。所要日数は収録日そのもの |
| 編集 | 6〜12人日 | 尺が長い、または素材が多い場合 |
| 確認 | 1〜2人日 | 確認する相手が3名以上いる場合 |
| 公開 | 1〜2人日 | 複数の公開先がある場合 |
| （予備日） | 0人日 | 標準作業ではない。量と位置は第3章 |

**書いてあるのは工数（人日）だけ。** 所要日数は `40-team.md` の人数と実働係数から式で出す
（`definitions/20-scheduling-rules.md` 第2章）。

```
有効人数 = 1 + (人数 − 1) × 0.7
所要日数 = ceil( 工数(人日) / (有効人数 × 実働係数) )
```

---

## 2. 倍率

**倍率は工数に掛ける。所要日数には掛けない。** 複数該当する場合は掛け合わせる。

| 規模 | 倍率 |
|---|---|
| 小さい | 0.5 |
| 標準 | 1.0 |
| 大きい | 1.5〜2.0 |

| 条件 | 倍率 |
|---|---|
| 初めての形式・初めての機材 | 1.3 |
| 社外の出演者・取材先が関わる | 1.3 |
| 公開先が複数ある | 1.2 |

---

## 3. バッファの量

| 種類 | 量 | 置き場所 |
|---|---|---|
| 収録バッファ（予備日） | 1稼働日以上 | 収録完了マイルストンの直前 |
| 編集バッファ | 編集工程の経過稼働日数の 20%、最低3稼働日 | 編集完了マイルストンの直前 |

**編集バッファの比率が高い（20%）のは、確認後の修正指示が読めないため。**
収録の予備日は、当日の中止・撮り直しに備えて必ず置く。

---

## 4. 並行と直列

**この章の全体に、次の2つが先に効く。**

| 先に効く決まり | 内容 |
|---|---|
| **同じ役割のタスクは重ねない** | 並行してよい組み合わせであっても、担当が同じ役割なら直列に置く（`40-team.md` 第2章） |
| 同時本数の上限 | 同時に走らせられる作業本数を超えない（`40-team.md` 第2章） |

### 並行してよい組み合わせ

| 先に進むもの | 並行して進めてよいもの | 着手のタイミング |
|---|---|---|
| 台本・構成 | 出演・取材先調整 | 台本が半分進んだ時点。出演者に必要な条件が見えた時点で打診する |
| 企画 | 取材・調査 | 企画が半分進んだ時点 |

**並べたあとに前後が逆転していないか確認する。**
後のタスクの開始日を先行タスクの開始日より前に置かない。

### 直列にすべき組み合わせ

| 順序 | 理由 |
|---|---|
| 台本・構成 → 収録・撮影 | 台本が固まらないと撮り直しになる |
| 収録・撮影 → 編集 | 素材が揃わないと編集できない |
| 編集 → 確認 → 公開 | 確認前に公開しない |

---

## 5. 工数と期間が大きく離れる作業

「出演・取材先調整」は、**手を動かす時間は短いが、相手の返事を待つ期間が長い。**
式で出した所要日数（1〜2人日 ÷ 実働係数）では実態に足りない。

| 決めること | 決まり |
|---|---|
| 所要日数 | 相手の都合の待ちを含めて 5〜15稼働日で置く。式は使わない |
| 工数 | 上の表の値をそのまま使う（1〜2人日） |
| 増員 | 効かない。相手の都合は人数で縮まらない |

**この待ちは増員でも並行化でも縮まない。** 目標日に間に合わない案件では、ここが期間の下限を決める
（`definitions/20-scheduling-rules.md` 第3章 Step 5）。

---

## 6. 同じ作業が繰り返し出るとき

同じ標準作業が1つのフェーズに2回以上出る場合（複数本の連載、複数回の収録など）、
**2回目以降の工数に係数を掛ける。**

| 何回目か | 工数に掛ける係数 |
|---|---|
| 1回目 | 1.0 |
| 2回目 | 0.7 |
| 3回目以降 | 0.5 |

下限は 0.5人日。数える範囲は同じフェーズの中。
**収録・撮影と出演・取材先調整には適用しない**（回数を重ねても当日の時間と相手の都合は減らない）。
適用したことを `meta.assumptions` に1行残す。

# プリセット: 受託案件の進行管理

| 項目 | 値 |
|---|---|
| id | `client-project` |
| 表示名 | 受託案件の進行管理 |
| 版数 | 2.1 |
| 最終更新 | 2026/09/07 |

取引先から請けた仕事を、引き合いから請求まで通して管理する用途のためのプリセット。
簡易版として整備してある。使い込む場合は `software-development` と同じ粒度まで書き足してよい。

---

## 1. こういう依頼のときに使う

- 取引先から請けた仕事の進行を管理したい
- 見積・契約・検収・請求といった、取引先とのやりとりが工程に含まれる
- 「検収」「納品」「請求」といった言葉が入力文に出てくる
- 相手の確認待ちが日程に効いてくる

## 2. こういう依頼には使わない

| こういう場合 | 使うプリセット |
|---|---|
| 契約は済んでいて、制作の進行だけを管理したい | 制作物に応じて `software-development` / `content-production` |
| 自社のプロダクト開発 | `software-development` |

---

## 3. 前提

- 取引先の確認・承認は自分たちで短縮できない
- 検収は取引先が行い、その期間は契約で決まっている
- 請求は検収の完了が条件になる
- 制作の中身そのものの工程は、この プリセットでは1つの工程にまとめて扱う

制作の中身を細かく管理したい場合は、このプリセットで全体を管理し、
制作部分だけを別のスケジュール（`software-development` など）として2本目に切り出す。

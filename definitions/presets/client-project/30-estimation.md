# かかる日数の基準

標準作業ごとの標準工数と、それに掛ける倍率。標準作業の一覧は `10-standard-tasks.md` にある。

## 1. 標準作業ごとの標準工数

| 標準作業 | 標準工数 | 上限側を採る条件 |
|---|---|---|
| ヒアリング | 2〜3人日 | 相手の関係者が3名以上いる場合 |
| 見積 | 2〜4人日 | 前例のない内容を含む場合 |
| 契約 | 1〜2人日 | 契約書の内容を新規に作る場合 |
| 制作 | 案件による | 内容から個別に見積もる |
| 社内確認 | 1〜2人日 | 提出物が3点以上ある場合 |
| 取引先の確認待ち | 0人日 | 期間は第4章。こちらの工数は常に 0 |
| 納品 | 1人日 | 納品物の形式が複数ある場合 |
| 請求 | 0.5人日 | — |
| （予備日） | 0人日 | 標準作業ではない。量と位置は第3章 |

**書いてあるのは工数（人日）だけ。** 所要日数は `40-team.md` の人数と実働係数から式で出す
（`definitions/20-scheduling-rules.md` 第2章）。

```
有効人数 = 1 + (人数 − 1) × 0.7
所要日数 = ceil( 工数(人日) / (有効人数 × 実働係数) )
```

**「取引先の確認待ち」だけは例外。** 工数 0 で期間だけを持つので、式を使わず第4章の日数をそのまま所要日数にする。

「制作」は内容に依存するため、標準値を持たない。
制作の中身を細かく見積もる必要がある場合は、そこだけを別のスケジュールに切り出す。

---

## 2. 倍率

**倍率は工数に掛ける。所要日数には掛けない。** 複数該当する場合は掛け合わせる。

| 規模 | 倍率 |
|---|---|
| 小さい | 0.5 |
| 標準 | 1.0 |
| 大きい | 1.5〜2.0 |

| 条件 | 倍率 |
|---|---|
| 初めての取引先 | 1.3 |
| 契約書を新規に作る | 1.3 |
| 相手側の窓口が複数いる | 1.2 |

**「取引先の確認待ち」には倍率を掛けない。** 相手の都合で決まる期間であり、こちらの条件で伸び縮みしないため。

---

## 3. バッファの量

| 種類 | 量 | 置き場所 |
|---|---|---|
| 制作バッファ | 制作工程の経過稼働日数の 15%、最低3稼働日 | 制作完了マイルストンの直前 |
| 納品バッファ | 2稼働日以上 | 納品完了マイルストンの直前 |

**比率が開発より高い（15%）のは、取引先からの差し戻しが読めないため。**

---

## 4. 取引先の確認待ちの標準

「取引先の確認待ち」の期間は、契約に定めがあればそれに従う。定めがない場合の既定値。

| 何を待つか | 標準 |
|---|---|
| 見積の確認 | 5稼働日 |
| 契約書の確認・押印 | 10稼働日 |
| 中間の確認・フィードバック | 3〜5稼働日 |
| 検収 | 10稼働日 |

**この待ちは増員でも並行化でも1日も縮まない。** 目標日に間に合わない案件では、
ここが期間の下限を決める（`definitions/20-scheduling-rules.md` 第3章 Step 5）。

### 変更時の影響

- ここの日数を短くすると全体の期間が縮むが、相手が守れなければそのまま遅延になる。契約に定めがある場合はその値を使う。

---

## 5. 並行と直列

**この章の全体に、次の2つが先に効く。**

| 先に効く決まり | 内容 |
|---|---|
| **同じ役割のタスクは重ねない** | 並行してよい組み合わせであっても、担当が同じ役割なら直列に置く（`40-team.md` 第2章） |
| 同時本数の上限 | 同時に走らせられる作業本数を超えない（`40-team.md` 第2章） |

並行してよい組み合わせは「制作」と「社内確認」（制作が半分進んだ時点から確認を開始する）のみ。

それ以外はすべて直列。取引の流れは前段が終わらないと次に進めないため。
「取引先の確認待ち」の間に別の作業を進めることはできるが、その場合も待ちそのものは独立したタスクとして残す。

**並べたあとに前後が逆転していないか確認する。**
後のタスクの開始日を先行タスクの開始日より前に置かない。

---

## 6. 同じ作業が繰り返し出るとき

同じ標準作業が1つのフェーズに2回以上出る場合（複数の納品物、複数回の中間確認など）、
**2回目以降の工数に係数を掛ける。**

| 何回目か | 工数に掛ける係数 |
|---|---|
| 1回目 | 1.0 |
| 2回目 | 0.7 |
| 3回目以降 | 0.5 |

下限は 0.5人日。数える範囲は同じフェーズの中。
**「取引先の確認待ち」には適用しない**（相手の所要時間は回数で減らない）。
適用したことを `meta.assumptions` に1行残す。

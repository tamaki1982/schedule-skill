# プリセット: イベント・キャンペーン運営

| 項目 | 値 |
|---|---|
| id | `event-campaign` |
| 表示名 | イベント・キャンペーン運営 |
| 版数 | 2.3 |
| 最終更新 | 2026/09/09 |

日付が先に決まっていて、そこに向けて準備を積み上げる用途のためのプリセット。
簡易版として整備してある。使い込む場合は `software-development` と同じ粒度まで書き足してよい。

---

## 1. こういう依頼のときに使う

- 「イベントをやる」「セミナーを開く」「キャンペーンを打つ」といった依頼
- 開催日・実施期間が先に決まっている、または早い段階で決まる
- 告知して人を集める工程が含まれる
- 当日の運営と、その後の振り返りまでが範囲に入る

## 2. こういう依頼には使わない

| こういう場合 | 使うプリセット |
|---|---|
| 動画や記事そのものを作ることが主目的 | `content-production` |
| 取引先から請けたイベントで、見積・契約・請求まで含める | `client-project` |
| 開発が主で、告知は付随的 | `software-development` |

---

## 3. 前提

- 開催日は外部に告知した時点で動かせなくなる
- 会場・配信環境・出演者の確保は、着手時点で目処が立っている
- 当日の運営は自分たちで行い、外部への委託は含まない

---

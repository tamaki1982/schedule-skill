# 標準作業

ソフトウェア開発で繰り返し出てくる作業の型。ここに書いた内容は**生成時に参照するだけ**で、出力される JSON には作業の名前しか残らない。

版 6.0 でタスク種別を削除したため、このファイルは種別の語彙表ではなく、標準作業の一覧になった。
以前の内容は `_archive/definitions/presets/software-development/10-task-types_v5.0_2026-09-06.md` にある。

## 1. 標準作業の一覧

| 標準作業 | 既定の担当役割 | 並行可否 | 増員が効くか | 説明 |
|---|---|---|---|---|
| 要件定義 | プロダクト管理 | 直列 | 効く | 対象範囲と機能仕様を決める。ここが動くと後続すべてが動く |
| 画面設計 | デザイン | 並行可 | 効く | 画面の構成と遷移。要件定義の後半から着手できる |
| 技術設計 | バックエンド実装 | 並行可 | 効く | データ構造と通信方式。画面設計と並行してよい |
| 基盤・環境構築 | バックエンド実装 | 並行可 | 効く | 実行環境、継続的インテグレーション、監視の整備 |
| サーバ側実装 | バックエンド実装 | 並行可 | 効く | サーバ側の実装。データ構造を先に固める |
| 画面側実装 | フロントエンド実装 | 並行可 | 効く | 画面側の実装。画面設計の確定分から着手できる |
| 結合 | フロントエンド実装 | 直列 | **効かない** | 画面とサーバをつなぐ。両側が揃うまで着手できない |
| 動作テスト | 検証 | 直列 | **効かない** | 結合テストと受け入れテスト |
| レビュー | プロダクト管理 | 並行可 | 効く | 成果物の確認。単独では1〜2稼働日 |
| 公開作業 | バックエンド実装 | 直列 | **効かない** | 本番反映、切り戻し確認、稼働監視 |
| 外部要因の待ち | （なし） | 並行可 | — | 外部サービスの審査待ちなど。縮められない待ち時間として置く |

**「増員が効かない」作業には、所要日数の計算で人数を掛けない**（`40-team.md` 第1章）。

- 結合 — つなぎ込みは分担しづらく、調整の待ちが支配的になる
- 動作テスト — 手順を通す時間そのものは人数で割れない
- 公開作業 — 手順が直列で、並行しても危険が増えるだけ

## 2. 予備日（バッファ）

**予備日は標準作業ではない。** 遅延を吸収するための空き時間であり、作業ではないため。

| 項目 | 値 |
|---|---|
| 表し方 | `isBuffer: true` |
| 工数 | 0人日 |
| 担当役割 | 付けない |
| 名前 | 何のための予備かが分かる名前にする（例:「実装バッファ」「公開前バッファ」） |

置く量と位置は `30-estimation.md` 第4章にある。

版 5.0 まではバッファも種別の1つ（`buffer`）として扱っていたが、
種別を削除したため `isBuffer` の真偽値だけで表す形になった。

## 3. 作業名の付け方

**画面に出るのは作業の名前だけ**なので、名前だけで意味が通る必要がある。

| 場面 | 付け方 | 例 |
|---|---|---|
| 工程を挟む形 | 工程名が上の行に出ているので、対象を繰り返さない | 工程「実装」の下に「データモデル実装」 |
| 工程を挟まない形 | **対象物を名前の先頭に置く** | 「機能A 要件定義」「機能A サーバ側実装」 |
| 同じ作業が1つのフェーズに複数出る | 何についての作業かで区別する | 「一覧画面 画面側実装」「詳細画面 画面側実装」 |

**標準作業の名前をそのまま使わない。** 「要件定義」だけの行が複数のマイルストンに並ぶと、どれがどれか分からなくなる。

## 変更時の影響

- 行を追加・削除すると、生成されるスケジュールに出てくる作業が増減する。**出力の形は変わらない**（標準作業は JSON に載らないため）。
- 「並行可否」を `直列` に変えると、その作業は他と重ならないように配置され、全体の期間が伸びる。
- 「増員が効くか」を「効かない」に変えると、体制を増やしてもその作業の所要日数が縮まなくなる。
- 既定の担当役割を同じ役割に寄せると、並行実行が制限されて期間が伸びる。
- サーバ側実装と画面側実装を1つにまとめると、両者を並行させられなくなり、期間が大きく伸びる。分けたまま運用する。
- 標準作業を足したら、`30-estimation.md` 第1章に標準値の行も足す。足さないと工数を推定で埋めることになる。
